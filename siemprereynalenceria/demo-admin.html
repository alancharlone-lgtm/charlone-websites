¿Cómo se conecta el Sheet con la Web?

Paso 1: Publicar el Sheet

El comerciante (o nosotros) hace: Archivo → Compartir → Publicar en la web. Esto genera una URL pública que nuestro JavaScript puede leer.

Paso 2: Copiar el ID del Sheet

De la URL docs.google.com/spreadsheets/d/1BxiMVs0XRA5.../edit sacamos el ID (la parte en negrita).

Paso 3: Pegar en el código

En whatsapp-cart.js cambiamos una sola línea:

// Antes (JSON local):
SHEET_ID: null,

// Después (Google Sheets):
SHEET_ID: '1BxiMVs0XRA5nFMd...',

¡Listo! La web ahora lee los productos directamente del Google Sheet del comerciante, en tiempo real.
